# Linux Server Administration Lab

## Présentation

Ce projet a pour objectif de développer mes compétences pratiques en administration des systèmes Linux à travers un laboratoire basé sur Ubuntu Server.

## Environnement technique

- Système d'exploitation : Ubuntu Server
- Virtualisation : VMware
- Accès distant : SSH
- Gestion de versions : Git

## Objectifs du projet

- Administration des utilisateurs et des groupes.
- Gestion des permissions Linux.
- Configuration et administration des services avec systemd.
- Configuration du service SSH.
- Analyse des journaux système.
- Surveillance des ressources système.
- Automatisation des tâches avec Bash.
